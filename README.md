# Bandeiras

Site para aprender as 193 bandeiras dos Estados-membros da ONU com as técnicas do livro "The Math Academy Way": grafo de famílias visuais, repetição espaçada hierárquica, diagnóstico adaptativo, remediação direcionada e XP calibrado em minutos. O motor é genérico e fica separado da aplicação a bandeiras.

Documentação completa ao fim da primeira versão.
